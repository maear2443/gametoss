# 승인/거절 리듬게임 🎮

인형 공장 컨셉의 리듬 게임! 안맞는 인형은 망치로 쳐내고, 맞는 인형은 승인하세요.

## 🎮 주요 기능

- **랜덤 캐릭터**: 매 노트마다 다양한 캐릭터가 랜덤으로 등장 (곰, 고양이, 토끼, 강아지, 여우)
- **탑 쌓기 비주얼**: 캐릭터들이 위에서부터 차곡차곡 쌓여 내려오는 연출
- **망치 & 기계팔 애니메이션**:
  - 거절(빨강) → 망치로 쳐내기
  - 승인(파랑) → 기계팔로 가져가기
- **효과음 시스템**: 4가지 상황별 효과음
  - 승인 성공 / 거절 성공
  - 승인 실패 / 거절 실패
- **랜덤 음악**: 게임 시작 시 플레이리스트에서 랜덤으로 음악 선택
- **1분 타이머**: 게임은 1분간 진행되며 종료 시 결과 화면 표시
- **판정 시스템**: PERFECT, GREAT, GOOD, MISS 4단계 판정
- **콤보 보너스**: 10콤보마다 +10점 추가 보너스!

## 🛠️ 코드 구조 (초보자도 쉽게 수정 가능!)

각 파일의 역할이 **기능별로 명확하게 그룹화**되어 있어 **AI로 개선하기도 쉽습니다**:

| 폴더/파일 | 역할 | 수정 예시 |
|----------|------|----------|
| **config/settings.js** | 🎚️ 숫자 조정 | BPM 범위, 판정 윈도우, 점수, 파티클 개수 |
| **game/Game.js** | 🎮 게임 진행 | 게임 시작/종료, 타이머, 노트 생성 |
| **game/Note.js** | 📦 노트 | 노트 모양, 크기, 애니메이션 |
| **game/scoring.js** | 💯 점수 | 판정 로직, 콤보 보너스 계산 |
| **visuals/renderer.js** | 🎨 렌더링 | 화면 그리기, 색상, 배경 |
| **visuals/effects.js** | ✨ 이펙트 | 파티클, 플래시, 링 효과 |
| **visuals/animations.js** | 🔨 애니메이션 | 망치/기계팔 속도 및 움직임 |
| **resources/loader.js** | 📦 리소스 | 이미지/음악/효과음 로딩 |
| **input.js** | 🎹 입력 | 키 바인딩, 버튼 클릭 처리 |
| **main.js** | 🚀 시작 | 초기화 순서, 모듈 연결 |

### 💡 초보자를 위한 팁

- **숫자를 바꾸고 싶다면**: `config/settings.js` 열기
- **게임 규칙을 바꾸고 싶다면**: `game/` 폴더 보기
- **화면 효과를 바꾸고 싶다면**: `visuals/` 폴더 보기
- **리소스를 추가하고 싶다면**: `resources/loader.js` 확인

## 🎵 음악 파일 추가하기

1. `assets/music/` 폴더에 MP3 파일을 추가하세요.
2. `assets/music/playlist.json` 파일을 수정하여 곡 정보를 추가하세요:

```json
{
  "songs": [
    {
      "name": "곡1",
      "file": "song1.mp3",
      "bpm": 120
    },
    {
      "name": "곡2",
      "file": "song2.mp3",
      "bpm": 95
    }
  ]
}
```

## 🎨 캐릭터 이미지 커스터마이징

현재 placeholder 이미지가 들어있습니다. 원하는 캐릭터 이미지로 교체할 수 있습니다:

- **이미지 크기**: 64px × 48px (가로로 약간 긴 납작한 형태)
- **형식**: PNG, 투명 배경 권장
- **경로**:
  - 거절용(빨강): `assets/images/red/`
  - 승인용(파랑): `assets/images/blue/`

각 캐릭터마다 red 버전과 blue 버전 2개씩 만들어주세요.

## 🔊 효과음 커스터마이징

현재 간단한 beep 효과음이 들어있습니다. 더 나은 효과음으로 교체할 수 있습니다:

- **효과음 종류** (4가지):
  - `approve_success.wav`: 승인 성공 시 (밝은 소리)
  - `reject_success.wav`: 거절 성공 시 (단호한 소리)
  - `approve_fail.wav`: 승인 실패 시 (불협화음)
  - `reject_fail.wav`: 거절 실패 시 (낮은 불협화음)
- **형식**: WAV 또는 MP3 (sounds.json에서 파일명 수정)
- **경로**: `assets/sounds/`

더 나은 품질의 효과음을 원하면 교체하세요!

## 🎮 게임 방법

1. **Start** 버튼을 눌러 게임 시작
2. 위에서 차곡차곡 쌓여 내려오는 인형들을 확인하세요
3. 타이밍 라인에 인형이 도착했을 때:
   - **안맞는 인형(빨강)**: `F` 키로 망치로 쳐내기
   - **맞는 인형(파랑)**: `J` 키로 기계팔로 승인하기
4. **콤보 시스템**: 10콤보마다 +10점 보너스!
5. **Space** 키로 일시정지/재개
6. **Reset** 버튼으로 게임 초기화
7. 1분이 지나면 자동으로 결과 화면이 표시됩니다

## ⚙️ BPM 조정

- 게임 중앙의 BPM 입력 필드에서 템포를 조정할 수 있습니다 (40-240)
- 랜덤 음악 선택 시 자동으로 해당 곡의 BPM이 적용됩니다

## 📝 점수 시스템

### 기본 점수
- **PERFECT**: +300점 (±50ms 이내)
- **GREAT**: +200점 (±100ms 이내)
- **GOOD**: +100점 (±150ms 이내)
- **MISS**: 0점 + 콤보 초기화

### 콤보 보너스
- **10 콤보**: 기본 점수 + 10점
- **20 콤보**: 기본 점수 + 20점
- **30 콤보**: 기본 점수 + 30점
- 계속 증가...

예시: 20콤보에서 PERFECT 달성 시 = 300 + 20 = **320점**!

## 🔧 개발 정보

- 순수 HTML5 + Canvas + JavaScript로 제작
- 외부 라이브러리 없이 동작
- 모든 리소스 로딩 실패 시 기본 박스로 표시 (graceful degradation)
- 망치 & 기계팔 애니메이션으로 생동감 있는 피드백
- 4가지 상황별 효과음 시스템

## ⚠️ 주의사항

- 음악 파일이 없으면 게임은 무음으로 진행됩니다
- 효과음 파일이 없으면 효과음 없이 진행됩니다
- 이미지 파일이 없으면 기본 색상 박스로 표시됩니다
- 현대적인 브라우저(Chrome, Firefox, Safari, Edge) 사용을 권장합니다
