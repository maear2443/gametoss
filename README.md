# 승인/거절 리듬게임

매 노트마다 랜덤 캐릭터가 나타나는 승인/거절 리듬게임입니다.

## 🎮 기능

- **랜덤 캐릭터**: 매 노트마다 다양한 캐릭터가 랜덤으로 등장 (곰, 고양이, 토끼, 강아지, 여우)
- **랜덤 음악**: 게임 시작 시 플레이리스트에서 랜덤으로 음악 선택
- **1분 타이머**: 게임은 1분간 진행되며 종료 시 결과 화면 표시
- **판정 시스템**: PERFECT, GREAT, GOOD, MISS 4단계 판정
- **콤보 시스템**: 연속으로 성공할 때마다 콤보 증가

## 🎵 음악 파일 추가하기

1. `assets/music/` 폴더에 MP3 파일을 추가하세요.
2. `assets/music/playlist.json` 파일을 수정하여 곡 정보를 추가하세요:

```json
{
  "songs": [
    {
      "name": "곡1",
      "file": "song1.mp3",
      "bpm": 120
    },
    {
      "name": "곡2",
      "file": "song2.mp3",
      "bpm": 95
    }
  ]
}
```

## 🎨 캐릭터 이미지 커스터마이징

현재 placeholder 이미지가 들어있습니다. 원하는 캐릭터 이미지로 교체할 수 있습니다:

- **이미지 크기**: 64px × 48px (가로로 약간 긴 납작한 형태)
- **형식**: PNG, 투명 배경 권장
- **경로**:
  - 거절용(빨강): `assets/images/red/`
  - 승인용(파랑): `assets/images/blue/`

각 캐릭터마다 red 버전과 blue 버전 2개씩 만들어주세요.

## 🎮 게임 방법

1. **Start** 버튼을 눌러 게임 시작
2. 위에서 떨어지는 노트가 타이밍 라인과 겹칠 때 키를 누르세요:
   - **거절 (빨강)**: `F` 키
   - **승인 (파랑)**: `J` 키
3. **Space** 키로 일시정지/재개
4. **Reset** 버튼으로 게임 초기화
5. 1분이 지나면 자동으로 결과 화면이 표시됩니다

## ⚙️ BPM 조정

- 게임 중앙의 BPM 입력 필드에서 템포를 조정할 수 있습니다 (40-240)
- 랜덤 음악 선택 시 자동으로 해당 곡의 BPM이 적용됩니다

## 🚀 실행 방법

1. 로컬 서버 실행:
   ```bash
   python3 -m http.server 8000
   ```

2. 브라우저에서 접속:
   ```
   http://localhost:8000
   ```

3. 또는 `index.html` 파일을 직접 브라우저로 열기

## 📝 점수 시스템

- **PERFECT**: +300점 (±50ms 이내)
- **GREAT**: +200점 (±100ms 이내)
- **GOOD**: +100점 (±150ms 이내)
- **MISS**: 0점 + 콤보 초기화

## 🔧 개발 정보

- 순수 HTML5 + Canvas + JavaScript로 제작
- 외부 라이브러리 없이 동작
- 모든 리소스 로딩 실패 시 기본 박스로 표시 (graceful degradation)

## ⚠️ 주의사항

- 음악 파일이 없으면 게임은 무음으로 진행됩니다
- 이미지 파일이 없으면 기본 색상 박스로 표시됩니다
- 현대적인 브라우저(Chrome, Firefox, Safari, Edge) 사용을 권장합니다
